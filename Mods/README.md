# tPlainModLoader 附加模组总览与使用手册

> **更新日期**：2026-08-24　**维护者**：SaintCirno9
> **适用环境**：Terraria 1.4.5.8 / tPlainModLoader (`net472`)

本目录包含 `tPlainModLoader` 原生支持的 8 个核心功能模组及 1 个辅助打包工具。所有模组均采用 **SDK 风格 + `net472`** 现代化架构，经过深度整编与性能优化，支持全量秒级构建与编译即部署（`dotnet build` 自动增量热部署至 `$(TerrariaDir)\tPlainModLoader\Mods\`）。

## 模组功能详述

### 1. 优化和工具 (OptimizeAndTool - 旗舰整合)
- **定位**：全能型游戏性能优化、全量 QoL 机制、便携存储与调试辅助合集（已深度融合原 `ReduceMouseLag`、`VeinMining`、`PipetteTool`、`AccessoryBox`、`CreativeInventory` 与 `SundryTool`）。
- **功能特性**：
  - **性能与输入优化**：
    - **硬件鼠标即时采样**：解除 60Hz 逻辑帧光标限制，渲染帧高频采样与 Win32 直采，消除光标粘滞感；
    - **视野缩放解除**：放宽原版视口缩放比例限制，适配超宽屏与远景宏观观察；
    - **光照性能优化**：优化多光源遍历管线。
  - **采矿与建造体验 (QoL)**：
    - **简单连锁挖矿**：破坏矿石/宝石时自动广度优先搜索连锁挖掘相连同类物块，支持配置数量上限与杂块过滤；
    - **吸管工具 (Pick Block)**：按 Q 键智能识别鼠标指向的物块/背景墙，并自动从背包或虚空袋拿出手持。
  - **扩展存储系统**：
    - **巨大随身背包 (BigBag)**：独立 40~500 格扩展大背包，支持 Shift 智能互存、一键整理、自动合并与便携合成；
    - **随身饰品收纳箱 (AccessoryBox)**：独立饰品箱，支持被动属性常驻挂载生效（词缀与饰品效果无需穿在身上）。
  - **规则与自动化 QoL**：
    - **9999 物品堆叠**：全物品堆叠上限提升至 9999；
    - **便携制作站与四箱**：随身猪猪存钱罐、保险箱、护卫熔炉与虚空保险库直连制作；
    - **无尽药水与随身增益**：药水达到阈值常驻赋予 Buff，携带增益站与怪物旗帜全局生效；
    - **城镇 NPC 优化**：自动入住、全员最高幸福度、旅商常驻、护士快速治疗；
    - **渔夫无冷却**：渔夫任务无等待时间，任务鱼可多持堆叠。
  - **创造与调试工具 (Cheat & Debug)**：
    - **创造物品栏 (Creative Inventory)**：全原版物品分类检索、分页与批量提取；
    - **全能作弊调试**：上帝模式无敌、自由穿墙与无限飞行、全图透视点亮、阻止感染蔓延、生态环境检测、射弹与实体属性透视；
    - **聊天增强**：连续重复信息自动防刷屏、一键复制聊天内容。

### 2. 快速设置 (QuickSetting)
- **定位**：游戏内即时模组配置中心。
- **功能特性**：
  - 在游戏界面提供抽屉式的统一设置菜单；
  - 供其它模组注册功能开关（Switch）、数值滑块（Slider）、文本输入框（TextBox）与按键绑定（KeyBind）；
  - 玩家可在游玩过程中实时开启/关闭黑科技或调整技能参数，无需返回标题画面。

### 3. 快速按钮 (QuickButton)
- **定位**：游戏内悬浮快捷工具栏基础设施。
- **功能特性**：
  - 在屏幕上生成一个可自由拖动位置的悬浮工具条；
  - 允许其它模组注册图标按钮（如饰品箱、魔杖工具、创造模式物品栏等）；
  - 支持鼠标悬浮说明、折叠/展开停靠以及按钮显示次序管理（`UIKeyOrder`）。

### 4. 足以改变泰拉大陆的魔杖 (WandsTool)
- **定位**：高级地形建筑、区域塑形魔杖与建筑结构导入导出蓝图库。
- **功能特性**：
  - **几何图形绘制**：直线（Line）、圆形/椭圆（Circular）、实心与空心矩形（Rectangle）；
  - **形态与坡度**：整砖（Solid）、半砖（Half-block）、4 种斜坡方向智能平滑；
  - **结构蓝图**：框选区域一键导出 JSON 结构蓝图，支持跨存档快速复制与放置。

### 5. 像素画生成 (PixelArt)
- **定位**：本地图像转泰拉瑞亚方块像素画生成器。
- **功能特性**：
  - 通过系统文件选择框导入本地 PNG / JPG 图片；
  - 内置色彩映射算法（`ColorToWall`），将图像色彩自动转为最接近的物块/背景墙颜色组合；
  - 支持像素尺寸缩放、生成锚点定位与区域预览，可在世界内快速摆放巨幅像素画。

### 6. 聊天 Ai (ChatAi)
- **定位**：大语言模型（LLM）游戏内聊天助手。
- **功能特性**：
  - 将 AI 接入游戏内聊天频道；
  - 支持输入特定前缀或指令向 AI 提问攻略、查询掉落或即兴对话；
  - 可在 `QuickSetting` 中自定义 API Endpoint、API Key、模型名称、温度系数与系统提示词（System Prompt）。

### 7. 魔法和技能 (Skil)
- **定位**：主动魔法与战斗动作模组。
- **功能特性**：
  - 提供 15+ 种独立主动技能（如光之女皇弹幕连招、双子魔眼激光扫射、环绕旋转刀刃、短距破空瞬移等）；
  - 支持在设置中自由配置技能消耗与冷却。

### 8. 可疑的玩家 (SuspiciousPlayer)
- **定位**：服务端原生兼容的高难度 BOSS 挑战事件。
- **功能特性**：
  - 手持史莱姆枪点击使用召唤高强度自定义 BOSS；
  - 具备多阶段攻击弹幕与激怒机制，击败后全端同步结算并掉落毕业四柱碎片。

### 9. 批量生成 (BatchSapwn)
- **定位**：开发者模组资产归档与批量分发构建工具。
