# tPlainModLoader 附加模组总览与使用手册

> **更新日期**：2026-08-24　**维护者**：SaintCirno9
> **适用环境**：Terraria 1.4.5.7 / tPlainModLoader (`net472`)

本目录包含 `tPlainModLoader` 原生支持的 14 个附加功能模组及 1 个辅助打包工具。所有模组均已完成 **SDK 风格 + `net472`** 现代化重构，支持在 Release 模式下自动增量复制部署至游戏目录的 `$(TerrariaDir)\tPlainModLoader\Mods\` 中。

## 模组功能详述

### 1. 减少鼠标延迟 (ReduceMouseLag)
- **定位**：高刷新率与低延迟鼠标输入优化（参考 tModLoader `High FPS Support`）。
- **功能特性**：
  - **即时采样**：解除原版将鼠标坐标更新绑定在 60Hz `Update` 逻辑帧的限制，在 `DoDrawPrefix` 与光标绘制前执行即时高频硬件级采样；
  - **零延迟光标**：光标以当前物理微秒位置渲染，在高刷屏（120Hz/144Hz/240Hz+）或关闭跳帧时彻底消除 60Hz 光标拖影与粘滞感；
  - **Win32 直采**：支持直接通过 Windows API 查询当前硬件光标绝对坐标，绕过 XNA 消息循环缓冲；
  - **联动配置**：支持在 `QuickSetting` 即时开关与采样模式切换，并在 `QuickButton` 悬浮栏显示状态。

### 2. 快速按钮 (QuickButton)
- **定位**：游戏内悬浮快捷工具栏基础设施。
- **功能特性**：
  - 在屏幕上生成一个可自由拖动位置的悬浮工具条；
  - 允许其它模组注册图标按钮（如饰品箱、魔杖工具、创造模式物品栏等）；
  - 支持鼠标悬浮说明、折叠/展开停靠以及按钮显示次序管理（`UIKeyOrder`）。

### 3. 快速设置 (QuickSetting)
- **定位**：游戏内即时模组配置中心。
- **功能特性**：
  - 在游戏界面提供抽屉式的统一设置菜单；
  - 供其它模组注册功能开关（Switch）、数值滑块（Slider）、文本输入框（TextBox）与按键绑定（KeyBind）；
  - 玩家可在游玩过程中实时开启/关闭黑科技或调整技能参数，无需返回标题画面。

### 4. 创造物品栏 (CreativeInventory)
- **定位**：全物品创造模式调取器（类似 Cheat Sheet / Hero's Mod）。
- **功能特性**：
  - 囊括原版游戏全部物品（武器、盔甲、饰品、方块、墙壁、消耗品、材料等）；
  - 多级分类与中文检索过滤；
  - 支持自定义单次提取数量与翻页；
  - 支持绑定快捷键直接呼出，并集成在 `QuickButton` 悬浮栏上。

### 5. 饰品箱 (AccessoryBox)
- **定位**：无限容量的便携饰品与装备收纳箱。
- **操作指南**：
  - **放入/复制**：手持饰品或物品点击空白/现有格子，即可将物品置入并复制；
  - **清空格子**：空手状态下点击已有物品的格子即可清空该格；
  - **删除槽位**：鼠标右键点击多余的格子可直接删除该槽位；
- **说明**：纯客户端 UI，适合随时存放备用配装与快速换装测试。

### 6. 足以改变泰拉大陆的魔杖 (WandsTool)
- **定位**：高级地形建筑与区域塑形魔杖（泰之魔杖）。
- **功能特性**：
  - **几何图形绘制**：直线（Line）、圆形/椭圆（Circular）、实心与空心矩形（Rectangle）；
  - **形态与坡度**：整砖（Solid）、半砖（Half-block）、4 种斜坡方向智能平滑；
  - **图格与墙体**：支持物块快速铺设、墙壁粉刷、物块替换；
  - **创造模式开关**：可在设置中选择是否消耗背包物品，具备半透明线框实时预览。

### 7. 像素画生成 (PixelArt)
- **定位**：本地图像转泰拉瑞亚方块像素画生成器。
- **功能特性**：
  - 通过系统文件选择框导入本地 PNG / JPG 图片；
  - 内置色彩映射算法（`ColorToWall`），将图像色彩自动转为最接近的物块/背景墙颜色组合；
  - 支持像素尺寸缩放、生成锚点定位与区域预览，可在世界内快速摆放巨幅像素画。

### 8. 优化和工具 (OptimizeAndTool)
- **定位**：日常游戏体验优化与信息辅助。
- **功能特性**：
  - **聊天优化**：自动过滤连续重复的刷屏聊天信息，支持一键复制聊天文本；
  - **服务器列表**：游戏内快捷服务器管理面板，记录常用服务器 IP、端口并支持快速直连；
  - **物品信息扩展**：鼠标悬浮显示物品的内部 ID、对应射弹 ID、伤害、击退、攻速、稀有度等详细数值；
  - **视距与光照**：解除部分视角缩放限制，优化光照遍历性能。

### 9. 聊天 Ai (ChatAi)
- **定位**：大语言模型（LLM）游戏内聊天助手。
- **功能特性**：
  - 将 AI 接入游戏内聊天频道；
  - 支持输入特定前缀或指令向 AI 提问攻略、查询掉落或即兴对话；
  - 可在 `QuickSetting` 中自定义 API Endpoint、API Key、模型名称、温度系数与系统提示词（System Prompt）。

### 10. 魔法和技能 (Skil)
- **定位**：玩家自定义魔法能力与主动战斗技能系统。
- **功能特性**：
  - 包含 15+ 种强大的主动技能与法阵机制；
  - **环绕弹幕**：周身旋转的射弹护盾，支持调节数量、半径与转速；
  - **双子眼扫射**：召唤机械眼发射激光雨，支持自动索敌或手动鼠标瞄准；
  - **光之女皇连招**：释放空灵长枪、太阳舞等高阶弹幕连招；
  - **位移神技**：短距相位瞬移、穿梭位移；
  - **参数微调**：所有技能的冷却（CD）、弹幕伤害与触发方式均可在 `QuickSetting` 中单独设定。

### 11. 杂项工具箱 (SundryTool)
- **定位**：全功能开发者与作弊辅助工具箱（杂鱼工具箱）。
- **功能特性**：
  - **玩家状态**：无敌模式（GodMode）、无限呼吸/法力、移动速度与飞行时间倍率、穿墙模式（Noclip）、超级吸怪/拾取范围；
  - **手持武器**：攻击范围倍增、自动连发强化、攻速倍率、伤害倍率、无限弹药；
  - **世界控制**：时间流速调整、昼夜锁定、天气变更、阻止地形腐化蔓延（`stopTileConvert`）；
  - **视觉透视**：全图开图（Map Revealer）、强光夜视（Light Hack）、感染区域指示器、玩家雷达；
  - **实体交互**：向玩家派发射弹/物品测试、箱子一键全开/清空/填满、粒子生成测试。

### 12. 可疑的玩家 (SuspiciousPlayer)
- **定位**：高难度多阶段挑战 BOSS 事件（完全适配多人联机与专用服务端）。
- **机制说明**：
  - **召唤方式**：手持 [史莱姆枪]（Slime Gun）射击虚拟玩家赋予 Buff 即可触发事件；
  - **阶段流程**：
    1. 克苏鲁之龙分裂召唤与血量削减；
    2. 光之女皇空灵长枪与太阳舞爆发弹幕；
    3. 天界四柱降临与护盾防御机制；
    4. 黑暗爆破法阵与火球狂轰；
  - **战利品**：击败后掉落大量天界四柱碎片，月总后击败额外掉落月总专属战利品；
  - **全端同步**：完全通过标准网络包同步，移动端与 PC 客户端均能完美体验。

### 13. 简单连锁挖矿 (VeinMining)
- **定位**：高效率智能连锁采矿辅助模组。
- **功能特性**：
  - 破坏矿石时自动连锁挖掘相邻相连的同类矿石（全矿石、沙漠化石与地下宝石支持）；
  - 采用 BFS 算法与最大破坏数量上限保护（可在设置中调滑块）；
  - 深度接入 `QuickSetting` 抽屉菜单与 `QuickButton` 悬浮工具栏。

### 14. 吸管工具 (PipetteTool)
- **定位**：类似 Factorio 的吸管工具（Pick Block）与物块快速选取。
- **功能特性**：
  - **快捷吸取**：指向场景中的物块或背景墙，按下快捷键（默认 `Q` 键）即可直接拿出手持；
  - **智能调度**：若快捷栏已持有则直接切换选中；若在主背包或虚空袋中，自动对调移入手持快捷栏并播放音效与提示浮字；
  - **多格家具识别**：自动解析火把、平台、箱子、工作台、床、门等复杂多格家具的对应款式物品；
  - **未持有提示**：当背包中没有该物块时，弹出醒目红色提示并播放警示音；
  - **自由配置**：支持在游戏内原版设置面板与 `QuickSetting` 抽屉菜单中自定义绑定按键与各项开关。

### 15. 批量生成 (BatchSapwn)
- **定位**：模组分发与打包辅助命令行工具。
- **功能特性**：
  - 读取 `生成配置.txt`，自动将各工程生成的 DLL、PDB 与 `info.json`、`loadConfig.json`、`ico.png` 提取并打包至指定发布文件夹。
